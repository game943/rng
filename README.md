# 🎲 Pet Roll Arena

A small browser RNG game: roll for pets, build a team of 3, and fight monsters.

Open `index.html` in any browser to play. Progress saves automatically in your browser.

- **Roll**: 50 🪙 per roll. Six rarities from Common (60%) to Mythic (0.1%). Every 50 rolls you're guaranteed Epic or better.
- **Pets**: equip up to 3 and sell the ones you don't need. Pets level up from battle XP.
- **Battle**: auto-battle that gets harder every stage. Every 5th stage is a boss. Win coins, then roll for stronger pets.
